What's the difference?

Capability OSS (self-hosted) Platform (managed)
Capture, scrubbing, lifecycle, auto-capture ✓ ✓
Masked session replay whole-session (auto) consent-gated, with user-controlled start/stop
Server admits replay only with recorded consent — ✓ enforced server-side
Operator controls (tenant replay policy, consent audit) — ✓
