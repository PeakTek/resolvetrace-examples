The server mints a per-session support code on session start — share it, then look it up in the portal. "Report a problem" sends a support.report_submitted event (carrying the code) → portal Reports.

Session replay

mode: —

Masked session replay. In auto mode the whole session is recorded (all-or-nothing); form inputs are always masked, static text stays readable. Chunks upload every ~5s of activity and appear on the session's portal detail page. Toggling reloads (the policy resolves when the client is created).
