Consent-gated replay

Why this matters: the server enforces replay consent in the data plane — a recording is admitted only for sessions with recorded consent, every decision is captured as an auditable record, and withdrawal takes effect in real time. This is what maps session replay to GDPR / CCPA / PIPEDA consent obligations.

One switch, like a real integration: allowing session replay records the end-user's consent and starts recording. Run guided demo shows what makes it Platform — the server admitting, then refusing, replay as consent changes — in ~30s.
