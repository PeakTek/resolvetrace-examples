Consent-gated replay Platform

Why this matters: consent is enforced by the server in the data plane — not a client-side honor system a developer can bypass. Replay is admitted only for sessions with recorded consent, every decision is captured as an auditable record, and withdrawal takes effect in real time. This is what maps session replay to GDPR / CCPA / PIPEDA consent obligations.

Two independent switches. The browser records whenever Record is on — but the managed server only admits chunks when consent is on file. The gap between them is the enforcement story. New here? Run guided demo walks the whole thing in ~30s.
